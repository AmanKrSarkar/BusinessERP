BusinessERP is a Python-based desktop ERP system built with PySide6 and SQLite for managing sales, purchases, inventory, customers, suppliers, payments, returns, cash, bank transactions, expenses, and business reports. It features batch-wise inventory, FIFO stock management, GST reporting, A5 invoice printing, Excel reports, automatic backups, and local database storage. The project is designed with a modular architecture so it can be easily maintained, upgraded, and packaged as a Windows application.
